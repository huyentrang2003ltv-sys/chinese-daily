# Học Tiếng Trung Mỗi Ngày (每日中文)

> **Slogan:** *多学一门外语, 多看一个世界, 多过一种人生*  
> *(Học thêm một ngoại ngữ, ngắm thêm một thế giới, sống thêm một cuộc đời)*

Nền tảng học tập Hán ngữ toàn diện, kết hợp phong cách thiết kế **Sang Trọng Phương Đông (Oriental Luxury & Heritage Elegance)** với các công nghệ tương tác học tập hiện đại nhất.

---

## ✨ Học Tập Hằng Ngày, Tài Khoản & Lớp Học

- **🏠 Trang chủ** – lời chào theo tài khoản, điểm danh hằng ngày, nhiệm vụ trong ngày (thẻ SRS đến hạn, mục tiêu EXP, luyện viết), *Chữ Hán của ngày* có hoạt họa nét viết, câu đố nhanh, tiếp tục bài đang học và **bảng vàng** xếp hạng theo EXP của các tài khoản thật.
- **👤 Tài khoản** – đăng ký/đăng nhập bằng email; mật khẩu băm `scrypt`, phiên đăng nhập là cookie HttpOnly có ký số. Tiến độ (EXP, chuỗi ngày, sổ tay, bộ thẻ SRS) **đồng bộ lên tài khoản** để học trên nhiều thiết bị; khách vẫn học được, tiến độ lưu trên trình duyệt và được chuyển vào tài khoản khi đăng ký.
- **💎 VIP** – 7 ngày dùng thử sau khi đăng ký; nâng cấp bằng chuyển khoản VietQR (thông tin ngân hàng cấu hình trên máy chủ), quản trị viên kích hoạt trong *Bảng quản trị*. Trạng thái VIP do máy chủ tính.
- **🧩 Xếp khối gỗ (汉语积木)** – trò chơi ghép câu 60 cấp.
- **🔁 Ôn tập ngắt quãng (SRS)** – Flashcard theo hệ Leitner: nhớ thì giãn lịch 1 → 2 → 4 → 7 → 15 → 30 → 60 ngày, quên thì quay lại sớm. 4 chế độ: *Đến hạn ôn*, *Học từ mới theo HSK*, *Sổ tay*, *Xem tự do*. Phím tắt Space / 1 / 2.
- **🏫 Lớp học** – giáo viên tạo bài kiểm tra từ vựng (theo cấp HSK, từ sổ tay hoặc danh sách tự chọn; 4 dạng câu hỏi) và gửi **link**; học sinh làm bài trên điện thoại, nhận **mã kết quả**; giáo viên dán mã để có bảng điểm, danh sách *từ cả lớp hay sai* và xuất **CSV**. Không cần tài khoản hay máy chủ cơ sở dữ liệu.
- **💾 Sao lưu tiến độ** – tải/khôi phục toàn bộ tiến độ (JSON) để chuyển sang máy khác.

> Mã kết quả có mã kiểm tra để phát hiện sao chép sai, nhưng do không có máy chủ nên không chống được gian lận có chủ đích – phù hợp cho bài tập rèn luyện, không dùng cho thi có tính điểm chính thức.

## 🌟 Các Phân Hệ Cốt Lõi

1. **🌳 Mô Hình Đại Thụ Ngữ Pháp (语法思维大树)**:
   - Kiến trúc cây đại thụ tương tác độc bản: Khởi phát từ **Gốc Rễ Tư Duy Cốt Lõi** (Thời gian & Không gian) tỏa xuống **6 Trụ Cột Nhánh Lớn** và bung nở thành **26 Nhánh Con Chi Tiết**.
   - Kèm công thức vàng, điều kiện ngữ cảnh, mẹo nhớ, ví dụ đối chiếu đảo ngược giữa tư duy Tiếng Trung và Tiếng Việt, cùng phát âm giọng đọc bản xứ.

2. **📖 Thư Viện Đọc Hiểu Song Ngữ Tương Tác (双语精读)**:
   - Tuyển tập 14 bài đọc hiểu chọn lọc phân tầng từ HSK 2 đến HSK 6:
     - **Chuyện Chữa Lành & Trưởng Thành**: Truyền cảm hứng từ kênh YouTube *Chinh phục tiếng Trung cùng Thơ*.
     - **Báo Chí Chính Thống & Thời Sự**: Trích dẫn từ *Tân Hoa Xã (新华社), Nhân Dân Nhật Báo (人民日报), China Daily (中国日报), CCTV News (央视新闻)*.
     - **Ngụ Ngôn & Cổ Điển**: *Thầy bói xem voi, Ngu Công dời núi, Ôm cây đợi thỏ, Vẽ rắn thêm chân*.
   - Tính năng chạm từ tra nghĩa tức thì (**Click-to-lookup**), bảng từ vựng trọng tâm (**Key Vocabulary**) và bài trắc nghiệm đọc hiểu (**Comprehension Quiz**) có chấm điểm & giải thích tự động.

3. **🖌️ 214 Bộ Thủ Khang Hy & Luyện Viết Hanzi (康熙部首与汉字书写)**:
   - Hệ thống hóa đầy đủ 214 bộ thủ Khang Hy chuẩn mực từ 1 đến 17 nét kèm biến thể, phiên âm, Hán Việt và ý nghĩa biểu trưng.
   - Tích hợp công nghệ hoạt họa viết nét bút thuận động (**HanziWriter**) và chế độ kiểm tra viết tay tương tác.

4. **⚖️ Ma Trận Phân Biệt Từ Dễ Lẫn (易混词辨析)**:
   - Phân biệt chi tiết các cặp từ dễ nhầm lẫn nhất trong đề thi HSK: `二` vs `两`, `刚` vs `刚才`, `常常` vs `往往`, `差不多` vs `几乎`, `以为` vs `认为`, `会` vs `能` vs `可以`... kèm Mini-quiz phản xạ nhanh 5 giây.

5. **🏛️ Cẩm Nang Ngữ Pháp Toàn Thư (语法全书) & Kho Tàng Thành Ngữ (成语典故)**:
   - Hệ thống hóa các mẫu câu đặc biệt (Câu chữ 把, 被, 是...的, 比), 7 loại bổ ngữ then chốt và trợ từ.
   - Thành ngữ 4 chữ kinh điển kèm điển tích lịch sử và bài tập thực hành.

6. **🤖 Trợ Lý AI Đàm Thoại & Đề Thi HSK Mô Phỏng**:
   - Luyện đàm thoại đa ngữ cảnh với AI.
   - Hệ thống khảo thí mô phỏng đề thi HSK chuẩn cấu trúc mới.

## 🚀 Hướng Dẫn Cài Đặt & Khởi Chạy

### Yêu Cầu Môi Trường
- [Node.js](https://nodejs.org/) 20.6 trở lên.

### Chạy trên máy cá nhân
```bash
npm install          # cài thư viện (node-edge-tts, tailwindcss)
npm run dev          # build CSS + chạy server tự khởi động lại khi sửa server.js
```
Mở `http://localhost:3005`. Trên Windows có thể bấm đúp `start.bat`.

Khi sửa class Tailwind trong `public/index.html` hoặc `public/js/**`, chạy `npm run watch:css` song song để CSS tự build lại.

### Kiểm tra trước khi commit
```bash
npm run check        # kiểm tra cú pháp + phát hiện handler gọi hàm không tồn tại
npm test             # bộ test API/bảo mật của server (node:test, không gọi dịch vụ ngoài)
```

### Quản trị tài khoản
Quyền quản trị **không bao giờ** được cấp qua web. Trên máy chủ:
```bash
npm run admin -- list                 # danh sách tài khoản
npm run admin -- grant you@example.com     # cấp quyền quản trị
npm run admin -- password you@example.com  # đặt mật khẩu mới (hủy các phiên cũ)
```
Chạy khi server đã dừng, hoặc khởi động lại server sau đó. Dữ liệu tài khoản nằm trong `storage/` (không commit, không phục vụ qua HTTP) – hãy sao lưu thư mục này.

Nâng cấp từ bản cũ: `deploy.sh` tự chép `data/users.json` sang `storage/legacy-users.json` và server nhập một lần. Tài khoản đang dùng mật khẩu mặc định cũ phải được đặt lại bằng `npm run admin -- password <email>`.

### Triển khai (production)
- **Docker:** `docker compose up -d --build` (ứng dụng chạy ở cổng 3000, có healthcheck `/healthz`).
- **VPS + PM2:** clone repo rồi chạy `sudo ./deploy.sh`.
- Đặt reverse proxy (Caddy/nginx) phía trước để có HTTPS; khi đó đặt `TRUST_PROXY=1`.
- Biến môi trường: xem `.env.example` (server tự đọc file `.env`). Không bao giờ commit file `.env`.
- Docker lưu dữ liệu tài khoản trong volume `./storage`.

### Cấu trúc thư mục
```
server.js              # điểm khởi động HTTP server
server/                # config, file tĩnh (chỉ public/), TTS, tài khoản & phiên, API, đếm truy cập, Telegram
storage/               # dữ liệu chạy thật: tài khoản, khóa phiên, bộ đếm (không commit)
test/                  # test API/bảo mật (npm test)
tunnel_manager.js      # (tùy chọn) mở tunnel Cloudflare/localhost.run và báo link qua Telegram
public/
  index.html           # khung giao diện + các section của từng tab
  styles.css           # theme "Oriental Luxury"
  assets/              # tailwind.css (được build, không commit), icon
  data/*.json          # dữ liệu học tập (nạp lười theo tab)
  js/core/             # utils, data loader, TTS, giao diện sáng/tối, hồ sơ, SRS, tài khoản, VIP, router
  js/features/         # mỗi tab một module
scripts/
  admin.js             # CLI quản trị tài khoản
  check-frontend.js    # kiểm tra tĩnh frontend
  data/                # script sinh/mở rộng dữ liệu JSON (chạy thủ công)
src/tailwind.css       # đầu vào Tailwind
```
